# Getting help

- **How do I…?** Start with the [README](README.md), the [user guide](docs/USER-GUIDE.md), the
  in-app *Help* page and the [troubleshooting guide](docs/TROUBLESHOOTING.md), which is indexed by
  the exact error message you see; [CONCEPTS.md](docs/CONCEPTS.md) explains harness2's vocabulary and the
  [administrator's guide](docs/ADMIN-GUIDE.md) covers installation and configuration. Still stuck?
  Open a GitHub Discussion (or an issue labelled `question`).
- **Something is broken:** open an issue with the bug template. Include `h2studio version`, the
  harness2 commit (Settings → System, or `h2studio doctor`), your isolation mode, the `request_id` of
  a failing API call, and redacted log lines. Never paste a token, a key or an unredacted log.
- **Security problem:** follow [SECURITY.md](SECURITY.md) — never a public issue.
- **harness2's own behaviour** (recursion, benchmarks, scores): that is the upstream research
  project, <https://github.com/google-research/harness2>.

Harness² Studio is an independent, unofficial project. It is not affiliated with, endorsed by or
supported by Google.
